# BI handoff

Serving agreement cho BI developer, không triển khai Power BI reports.

Trạng thái: PROPOSED boundary; documentation foundation, chưa có runtime/config executable.

- Bàn giao hai contracts: pilot learning status và pilot qualification status.
- Ghi typed fields, grain/keys/relationships, measures/denominators, access và freshness.
- Kèm sample queries/expected results tránh fan-out, publication selection và drill-down grain.
- Cutoff/deadline/timezone/late-source policy và Power BI refresh integration còn cần chốt.
