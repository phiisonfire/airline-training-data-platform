# Contracts

Versioned source/canonical/reporting/backfeed/configuration agreements.

Trạng thái: PROPOSED boundary; documentation foundation, chưa có runtime/config executable.

- Trước mỗi product chốt grain, tenant/business/surrogate keys, types/nullability, relationships, owner và compatibility.
- Source contracts pin upstream commit/release/contract; docs mockgen links chưa tồn tại locally không là implementation evidence.
- Reporting gồm learning targets kể cả thiếu evidence và qualification status theo publication.
- Backfeed logical contract khác actual app SQL DDL; schema/enums/lifecycle/write ownership cần xác nhận.
- Đồng bộ validators, transformation outputs, DDL và consumers khi có implementation.
